# loc-oss.github.io

The official website for **Lines of Code** — a community of OSS enthusiasts building minimalist, local-first, and independent software.

This repository contains the source code for our landing page and project documentation. The site is built with Jekyll and hosted on GitHub Pages.

## Tech Stack

- **Jekyll** (Static Site Generator)
- **HTML / CSS** (Minimalist, zero-dependency frontend)
- **GitHub Pages** (Hosting)

## Local Development

If you want to run the site locally to preview your changes, you will need to have Ruby and Jekyll installed.

```bash
# Clone the repository
git clone https://github.com/loc-oss/loc-oss.github.io.git

# Navigate to the directory
cd loc-oss.github.io

# Serve the site locally
bundle exec jekyll serve
```

The site will be available at `http://localhost:4000`.
