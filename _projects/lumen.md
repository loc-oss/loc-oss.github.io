<div class="container project-content">
  <h1>Lumen</h1>
  <p><strong>Goal:</strong> Build a lightning-fast, GPU-accelerated text editor.</p>
  <p><strong>Stack:</strong> Rust (core) and C (bindings). No Electron. No JavaScript.</p>
  <p><strong>Core:</strong> Based on the modernized <code>xi-editor</code> core.</p>
  <p><strong>Vibe:</strong> Minimal UI. Vim-like keybindings. Memory footprint < 20MB.</p>

  <p><strong>Concept:</strong> "Lumen" stands for speed and clarity. The editor should open instantly and get out of the developer's way.</p>

  <h3>Status</h3>
  <p>Core is stabilized and builds on recent Rust (forked from the abandoned xi-editor). Frontend development is next.</p>
