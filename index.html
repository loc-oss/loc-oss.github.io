// Philosophy

Minimalism

Simple solutions over complex abstractions. Less code means fewer bugs. Clean architecture.

Local-First

User data should remain on the user's device. Tools that work fast without a mandatory cloud dependency.

Quality

A small, well-tested codebase is better than a massive, unmaintained one.
